# voice_app_new

A new Flutter project.

## Running

The app calls the OpenAI Whisper API directly and needs a key injected at build/run time
(it is intentionally not hardcoded in the source):

```
flutter run --dart-define=OPENAI_API_KEY=sk-...
```
